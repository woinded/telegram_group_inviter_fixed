# ربات مدیریت دعوت تلگرام

## امکانات نسخه اولیه
- منوی فارسی
- ثبت لینک گروه‌های مبدأ
- ثبت لینک دعوت گروه مقصد
- نمایش تنظیمات ثبت‌شده در همان اجرای برنامه
- محدودسازی پنل به مدیر با `ADMIN_ID`
- بدون استخراج اعضا یا پیام انبوه ناخواسته

## راه‌اندازی
1. در سرویس میزبانی یک Python Worker بسازید یا از `render.yaml` استفاده کنید.
2. متغیرهای محیطی را تنظیم کنید:
   - `BOT_TOKEN`: توکن دریافتی از BotFather
   - `ADMIN_ID`: شناسه عددی تلگرام مدیر (اختیاری، ولی توصیه می‌شود)
3. برنامه را اجرا کنید؛ دستور شروع ربات `/start` است.

## نکات
- این نسخه تنظیمات را فقط در حافظه نگه می‌دارد؛ با راه‌اندازی مجدد پاک می‌شوند.
- ربات‌های تلگرام نمی‌توانند فهرست اعضای هر گروه دلخواه را استخراج کنند و صرف داشتن لینک گروه، مجوز افزودن اعضا نیست.
- برای دعوت اشخاص، از لینک دعوت در جایی استفاده کنید که کاربران بتوانند داوطلبانه عضو شوند یا فقط به افرادی پیام دهید که خودشان ابتدا ربات را باز کرده‌اند.
- هرگز توکن را در چت عمومی یا کد منتشرشده قرار ندهید. اگر توکن افشا شد، از BotFather آن را لغو و توکن تازه بگیرید.
